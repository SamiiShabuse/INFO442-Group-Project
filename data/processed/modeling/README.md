# Modeling Outputs

This folder stores model predictions and evaluation metrics.

## Folder Structure

- `linear_regression/`
- `random_forest/`
- `gradient_boosting/`
- `ridge_regression/`
- `neural_network_mlp/`
- `garch/`
- `feature_selection/`

Each prediction-model folder contains:

- `test_predictions.csv`
- `metrics.csv`

These files are generated by the notebooks in `notebooks/04_modeling/`. Keeping one folder per model makes comparison easier and prevents model outputs from being mixed together.

The MLP output uses `neural_network_mlp_prediction` as its prediction column,
which allows the dashboard Prediction Explorer to detect it automatically.
GARCH is SPY-only and is kept separate in the final comparison outputs.
