# Portfolio Optimization Outputs

This folder stores generated portfolio optimization outputs.

## Existing Backtest Outputs

- `portfolio_performance_metrics.csv`: summary metrics for portfolio strategies.
- `portfolio_strategy_weights.csv`: strategy allocation weights.
- `portfolio_daily_returns.csv`: daily portfolio return series.
- `portfolio_cumulative_returns.csv`: cumulative portfolio return series.

These files are generated by the portfolio optimization notebook.

## Live / Paper Rebalance Outputs

- `live_weights/`: target portfolio weights generated from the latest Random Forest prediction.
- `paper_orders/`: dry-run rebalance order CSVs created from those target weights.
- `sample_current_positions.csv`: optional fake holdings file for testing true rebalancing behavior.

The rebalance order files are simulation outputs. They show the buy/sell/hold
instructions that would move a portfolio toward the optimized target weights,
but they do not submit trades to a broker.
