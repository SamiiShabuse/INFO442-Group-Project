# Feature Data

This folder contains the model-ready feature dataset, selected feature list,
and latest feature snapshot used by the live Random Forest workflow.

Generated by:

- `notebooks/03_features/01_feature_engineering.ipynb`
- `notebooks/03_features/02_feature_selection.ipynb`
- `scripts/refresh_latest_features.py`

Expected files:

- `feature_engineered_dataset.csv`: full candidate feature set used as the
  input to feature selection and model training notebooks.
- `selected_features.csv`: final selected model feature list, one feature per
  row, used by all all-ticker models and live prediction scripts.
- `feature_selection_summary.csv`: ranking table for every candidate feature,
  including target correlation, Random Forest importance, mutual information,
  and drop reason.
- `latest_feature_snapshot.csv`: latest model-ready feature snapshot used by
  the exported Random Forest model to generate live predictions.

`latest_feature_snapshot.csv` is not a prediction file. It is the input table
that the model sees. Predictions are written under
`data/processed/modeling/random_forest/live_predictions/`.
