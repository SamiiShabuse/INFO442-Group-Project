# Predictive vs Historical Volatility Outputs

Generated by `notebooks/09_predictive_vs_historical/01_rf_vs_baseline_portfolio_impact.ipynb`.

These files support the project's central claim about whether predicted volatility improves portfolio
outcomes. The report, dashboard, and final slides should cite these files rather than re-deriving the
numbers, so every deliverable stays consistent.

## Forecast accuracy

- `forecast_accuracy_vs_baseline.csv`: MAE, RMSE, and R2 for the Random Forest and the
  historical-volatility baseline over the test period, pooled across all tickers.
- `forecast_accuracy_by_ticker.csv`: the same comparison per ticker, with the RMSE improvement and a
  flag for whether the Random Forest won.
- `forecast_skill_decomposition.csv`: splits the headline R2 into cross-sectional skill (ranking
  which assets are risky) and time-series skill (timing a single asset's volatility changes).

## Portfolio backtest

Rebalanced every 20 trading days, matching the model's forecast horizon.

- `rebalanced_strategy_performance.csv`: annualized return, annualized volatility, Sharpe ratio,
  max drawdown, and cumulative return for each strategy.
- `rebalanced_daily_returns.csv`: daily return series per strategy.
- `rebalanced_cumulative_returns.csv`: cumulative growth-of-$1 series per strategy.

Strategies covered: `Equal Weight`, `Historical Min Vol (matched)`, `Historical Min Vol (252d cov)`,
`RF Predictive Min Vol`, and `SPY Benchmark`.

`Historical Min Vol (matched)` is the controlled comparison — it uses the identical covariance
construction as the Random Forest strategy, differing only in the volatility input.

## Robustness

- `rebalance_frequency_sweep.csv`: the backtest repeated at 5, 10, 20, 40, 60, and 120 trading-day
  rebalancing frequencies.

Read this file before quoting any single backtest result. The volatility advantage of the Random
Forest is positive at every frequency, but the Sharpe advantage changes sign, so only the volatility
finding is safe to report as a conclusion.

## Risk model calibration

- `risk_model_calibration.csv`: mean predicted versus mean realized portfolio volatility, the bias,
  and mean absolute error for the Random Forest and matched-baseline risk models.

Both risk models understate risk, which is expected since correlations are estimated in calmer
conditions. The Random Forest's bias is roughly a third the size of the baseline's.
