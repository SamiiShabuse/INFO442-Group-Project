# Modeling Outputs

This folder stores model predictions, evaluation metrics, and model-specific
artifacts that are generated after feature engineering.

## Folder Structure

- `linear_regression/`
- `random_forest/`
- `gradient_boosting/`
- `ridge_regression/`

Each model folder should contain:

- `test_predictions.csv`
- `metrics.csv`

Model folders may also contain exported model files, metadata, live prediction
runs, and live evaluation outputs when that model is used outside the notebook.

These files are generated by the notebooks in `notebooks/04_modeling/`. Keeping one folder per model makes comparison easier and prevents model outputs from being mixed together.
